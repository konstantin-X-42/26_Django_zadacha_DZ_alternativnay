26 Формы в Django
1. Для создания и редактирования сущностей модели «собака» создайте формы.
2. Создайте новую модель «предок» с полями: собака (ссылка через внешний ключ), кличка, порода, год рождения.
3. Для формы редактирования собаки выведите формсет с возможностью заполнить родословную через указание предков.
4. Все формы необходимо стилизовать.
5. Для формы модели «собака» опишите валидацию, в которой будет проверяться,
   что дата рождения указана не ранее чем 100 лет назад.

24 Шаблонизация в Django

1. Подключить статические файлы бутстрапа к проекту, настроить директории для хранения статических файлов
2. Создайте контроллер для отображения одной собаки. Добавьте шаблон, в который будет
   выводиться вся информация по собаке
3. На главную страницу выведите всех собак, которые есть в базе. На странице отображайте
   название и описание в каждой карточке.
4. Реализуйте кнопку перехода на страницу одного товара и обратно
5. Выделите базовый шаблон для шаблонов. Подключите базовый шаблон в уже имеющиеся в проекте шаблоны.

23 Работа с ORM в Django
1. Подключить к проекту СУБД PostgreSQL, произвести необходимые настройки
2. Создать приложение с собаками. В приложении создать модели собаки и породы.
   Собака — с полями: имя, порода, фото, дата рождения. Порода с полями: название и описание.
3. Свяжите модель собаки с моделью породы через FK.
4. Настройте админку. В админку выведите id и название пород, а также имя и породу собак.
   Для собак добавьте фильтрацию по породам.
5. Создайте фикстуру для базы с помощью команды. Очистите базу и накатите фикстуру на чистую базу
6. Установите ipython и с помощью инструмента shell создайте породу и собаку с помощью прямого ORM запроса.
   Получите данные о собаке по имени (get). Выведите собак подходящих под определенные критерии (filter).
   Выведите все породы, которые записаны в БД (all)
